# Ambient Music Generator

Web Audio APIでアンビエント音楽を自動生成する、ブラウザ完結型のウェブアプリです。調性、モード、景色、密度、時間帯、音のレイヤーを組み合わせ、アコースティック楽器と環境音を使った演奏を生成します。

## 使い方

Node.jsがあれば、次のコマンドでローカルサーバーを起動できます。

```bash
npm start
```

ブラウザで `http://localhost:4173` を開き、「はじめる」を押してください。音の再生には、最初の操作でブラウザの音声再生許可が必要です。

## 構成

- `index.html`、`style.css`: 画面とスタイル
- `app.js`: Web Audio APIによる再生・レイヤー制御
- `music-theory.js`、`arrangement.js`: 音楽理論とアレンジ生成
- `acoustic-bank.js`: 実録音サンプルの定義
- `assets/`: 楽器・環境音とライセンス情報
